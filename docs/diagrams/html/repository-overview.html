左欄是使用端專案的輸入，中間是 edge_core 的共用主幹，右欄拆成 App Backend 與 External Systems。 實線表示直接資料流，虛線表示 runtime / subscription 類的 side channel。

Boundary 01

使用端專案

inputs

場域專屬的入口、排程與模型。這一側只供應 edge_core 需要的資料，不承擔共用 runtime。

使用端專案入口 → edge_core/main.py
專案入口會先進入 launcher，再交給共用 runtime。
schedules / configs / weights → edge.config
使用端專案控制的設定來源，直接影響 runtime 行為。
自訂模型 → edge.pipeline
自訂模型掛到 pipeline，而不是寫進共用框架。

Boundary 04

External Systems

outputs

外部邊界同時包含輸入、輸出與監控。camera 進入 pipeline， stream sink 接收視覺輸出，monitoring endpoint 接收 runtime 狀態。

RTSP / file / camera → edge.pipeline
影像來源進入 pipeline，成為 frame 的上游輸入。
stream sink ← edge.pipeline
pipeline 將視覺結果輸出到串流端。
monitoring endpoint ← edge.runtime
runtime 的健康與狀態回報會往這裡送。

Reading order. 使用端專案 feeds edge_core/main.py, edge.main fans out to the shared runtime modules, and the right-hand boundaries preserve the dotted backend and monitoring edges.
