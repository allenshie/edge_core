Quick read
這張圖的重點

edge.main 是主分岔點

它把 config、messaging、runtime 與 pipeline 接起來，是整個圖最重要的 hub。

runtime helpers 是支撐層

這些模組不直接處理 frame，但它們讓啟動、health 與摘要回報都能正常工作。

pipeline 與 helpers 分層很清楚

tasks 負責流程，helpers 負責實作細節。這是維護 edge_core 時最需要看的切面。
